# معاينات صور المتجر
هذه لقطات من نسخة المتصفح بتاريخ ٤ أكتوبر ٢٠٢٦ لتخطيط الصور، وليست لقطات iPhone أو iPad صالحة للإرسال النهائي. العناوين وترتيب الصور في APPSTORE_RELEASE.md. تُستبدل بلقطات حقيقية من build iOS النهائي ثم تركب عناوين التسويق بدون إخفاء تجربة اللعب. التقطها بالمقاسات المطلوبة من Apple وقت الرفع.
